# NumPy and Pandas Series - Assignment

NumPy aur Pandas Series ke 40 questions ka assignment, Google Colab par banaya hai.

## Sections
- **Section A (Easy):** Q1 se Q20
- **Section B (Moderate):** Q21 se Q34
- **Section C (Difficult):** Q35 se Q40

## Topics
- NumPy arrays, `arange`, `linspace`, `full`, reshape, transpose
- Indexing, slicing, Boolean indexing, `np.where()`
- Statistics (mean, median, variance, std) with `axis`
- Matrix multiplication, view vs copy
- Random data with fixed seed
- Pandas Series: labels, dictionary, filtering, `isnull()` / `notnull()`
- Index alignment and missing values (NaN)
